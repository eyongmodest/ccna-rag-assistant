# CCNA RAG Study Assistant

A free, local, question-answering assistant built on top of your own CCNA study PDFs. Ask a question in plain English, and it retrieves the most relevant passages from your material and generates a grounded answer — complete with the exact PDF filename and page number each answer came from.

Built as a Retrieval-Augmented Generation (RAG) pipeline: a free local embedding model handles search, and [Groq](https://groq.com)'s free-tier API handles answer generation. No paid API credit required.

## How it works

1. **Ingestion** (`src/ingest.py`) — loads your PDFs, splits them into chunks, converts each chunk into a searchable vector embedding (using a free local Hugging Face model), and stores everything in a local ChromaDB vector database.
2. **Query** (`src/query.py`) — takes your question, searches the vector database for the most relevant chunks, and sends them to an LLM (via Groq) to generate an answer grounded in your material — never guessing beyond what the retrieved text supports.

## Requirements

- Python 3.10+
- Windows, macOS, or Linux (developed and tested on Windows via Git Bash)
- A free [Groq](https://console.groq.com) API key (no credit card required)
- Your own PDF study material (not included in this repo — see note below)

## Setup

```bash
# Clone the repo
git clone https://github.com/YOUR-USERNAME/ccna-rag-assistant.git
cd ccna-rag-assistant

# Create and activate a virtual environment
python -m venv venv
source venv/Scripts/activate   # Windows (Git Bash)
# source venv/bin/activate      # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Set up your API key
cp .env.example .env
# then open .env and add your GROQ_API_KEY
```

## Usage

**1. Add your PDFs**

Place your own study PDFs into `data/raw/`. This repo does not include any PDFs — see the note below.

**2. Build the knowledge base**

```bash
python src/ingest.py
```

Run this once, and again any time you add new PDFs to `data/raw/`.

**3. Ask questions**

```bash
python src/query.py
```

Type a question and press Enter. Type `exit` to quit.

```
Your question: what is UDP

Answer: UDP is the User Datagram Protocol, a best-effort, connection-less
transport layer protocol that does not provide sequencing, reliability,
or flow control...

Sources:
  - networking-fundamentals.pdf (page 42)
```

## Tech stack

| Purpose | Tool |
|---|---|
| Orchestration | [LangChain](https://www.langchain.com/) |
| PDF loading | pypdf |
| Text splitting | LangChain text splitters |
| Embeddings (free, local) | Hugging Face `sentence-transformers/all-MiniLM-L6-v2` |
| Vector database | [ChromaDB](https://www.trychroma.com/) |
| LLM (free tier) | [Groq](https://groq.com) — `openai/gpt-oss-20b` |

## A note on the PDFs

This repo intentionally does **not** include any study PDFs. CCNA study material is typically copyrighted, and this project is meant to work with *your own* legally obtained materials. Bring your own PDFs, drop them in `data/raw/`, and run the ingestion step.
